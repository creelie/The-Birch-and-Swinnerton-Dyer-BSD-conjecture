# Repositories

Checked on 3 November 2026.

## Data and databases

| Repository | Content |
|---|---|
| [JohnCremona/ecdata](https://github.com/JohnCremona/ecdata) | Cremona's tables: all elliptic curves over $\mathbf Q$ of conductor below 500,000 with ranks, generators, BSD invariants and analytic $Ш$ (Zenodo concept DOI 10.5281/zenodo.593611). |
| [LMFDB/lmfdb](https://github.com/LMFDB/lmfdb) | The L-functions and Modular Forms Database: curves, $L$-functions, BSD data, Galois images. |

## Software

| Repository | Content |
|---|---|
| [JohnCremona/eclib](https://github.com/JohnCremona/eclib) | mwrank (2-descent), modular symbols, the tables' engine. |
| [sagemath/sage](https://github.com/sagemath/sage) | Elliptic curves, $p$-adic $L$-functions and regulators, `prove_BSD`, Heegner points. |
| [BarinderBanwait/rank2sha](https://github.com/BarinderBanwait/rank2sha) | Code (and Lean) for Banwait 2026, $Ш[p^\infty]$ for rank-2 CM curves via second derivatives of $p$-adic $L$-functions. |
| [jbalakrishnan/AWS](https://github.com/jbalakrishnan/AWS) | Arizona Winter School 2020: computational tools for quadratic Chabauty ($p$-adic heights). |
| [mmasdeu/darmonpoints](https://github.com/mmasdeu/darmonpoints) | Sage package for Darmon (Stark–Heegner) points. |
| [TimoKellerMath/strongBSDgenus2](https://github.com/TimoKellerMath/strongBSDgenus2) | Code for KellerStoll2025, complete verification of strong BSD for many modular abelian surfaces. |
| [alexanderbarrios/BSDmodsquares](https://github.com/alexanderbarrios/BSDmodsquares) | Code for the BSD formula modulo squares for quadratic twists. |
| PARI/GP (pari.math.u-bordeaux.fr, not on GitHub) | `ellanalyticrank`, `ellbsd`, `ellrank`, `ellpadicL`, `ellpadicbsd`; used by `../checks/`. |
